PikaPDF

Windows용 가볍고 빠른 PDF 뷰어·주석 도구. 설치 없이 폴더 하나로. 무료·오픈소스(GPLv3).

내려받기 (Windows 64비트) GitHub 저장소

되는 것

보기탭 여러 개, 검색, 목차·썸네일, 두 쪽 보기, 프레젠테이션. 한글 PDF도 깨끗하게.
주석형광펜(여러 색), 자유 그리기, 텍스트 메모, 이미지 넣기, 서명, 댓글, 양식 입력.
저장Ctrl+S로 원본에 바로 저장(직전 원본 자동 백업), 다른 이름으로 저장, 인쇄.
페이지삭제·잘라내기·복사·추출·순서 바꾸기, 다른 PDF나 이미지 합치기, 회전 저장(주석 유지).
도구용량 줄이기·잠금 해제(Ghostscript), 이미지 추출, PDF→이미지/텍스트/Word, 오피스·한글 문서→PDF.
그림→PDFJPG·PNG·TIFF·WebP·HEIC 등을 PDF로, 여러 장은 하나로 합치기. 탐색기에서 그림을 우클릭해 바로 변환. JPG는 다시 압축하지 않아 화질 그대로.
빠름더블클릭에서 첫 화면까지 약 1초. 이미 떠 있는 창에 새 탭은 0.1초대.

어떻게 만들었나

Firefox의 PDF 엔진 PDF.js를 Windows 내장 WebView2 창에 올리고, C# 호스트가 파일 저장·탭·도구를 맡습니다. Visual Studio 없이 Windows에 기본 포함된 C# 컴파일러만으로 빌드됩니다. 같은 제작자의 XPS 피팅 프로그램 PikaXPS와 한 식구입니다.
