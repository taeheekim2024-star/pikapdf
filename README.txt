PDF 뷰어
========

Firefox의 PDF 엔진(PDF.js 6.4)을 Windows 내장 WebView2 창에 올린 단독 실행 프로그램입니다.
설치 프로그램 없이 이 폴더만 있으면 동작합니다. (WebView2 런타임은 Windows 11에 기본 포함)

■ 창 구성
  남색 제목 표시줄 아래 탭 줄: 탭을 누르면 전환, × 또는 가운데 버튼으로 닫기, "+"로 열기, 빈 자리를 끌면 창 이동·두 번 누르면 최대화
  탭 줄 오른쪽의 파일·도구·도움말이 메뉴입니다. 저장 안 한 변경이 있는 탭은 이름 앞에 점이 붙습니다.
  빈 탭은 시작 화면입니다: 파일 열기, 그림을 PDF로, 오피스·한글 문서를 PDF로, 최근 문서 목록(누르면 열림), 끌어다 놓기.

■ 보기·편집 (뷰어 툴바)
  보기, 검색(Ctrl+F), 목차/썸네일 사이드바, 확대/축소, 두 쪽 보기, 프레젠테이션(Ctrl+Alt+P)
  형광펜(글자 선택 → 색 고르기), 자유 그리기, 텍스트 메모, 이미지 넣기, 서명, 댓글, 양식 입력
  인쇄(Ctrl+P), 저장(Ctrl+S: 원본에 바로 덮어쓰기), 다른 이름으로 저장(Ctrl+Shift+S)
  서명과 넣은 그림(도장)은 저장할 때 쪽의 일부로 박아 넣습니다. 그러면 다른 프로그램에서 주석처럼 따로 집어 옮기거나
  복사·삭제할 수 없습니다. 저장하기 전까지는 옮기거나 지울 수 있고, 저장한 파일을 다시 열면 고칠 수 없습니다.
  다른 주석이나 양식 칸 위에 겹쳐 놓은 것, 댓글을 단 것은 박아 넣지 않고 주석으로 저장하며, 그때는 알려 줍니다
  (박으면 그 밑에 깔려 가려지거나 댓글이 없어지기 때문입니다). 쪽을 지우거나 순서를 바꾼 저장, 합친 문서의 저장에서도 박아 넣습니다.
  (끄려면 도구 메뉴의 "저장할 때 서명·그림을 자동으로 박아 넣기" 체크를 푸세요. 그러면 예전처럼 주석으로 저장됩니다.)
  PDF 더블클릭, 끌어다 놓기, Ctrl+O 모두 새 탭으로 열립니다 (이미 열린 파일은 그 탭으로 이동).
  페이지 관리: 왼쪽 사이드바(맨 왼쪽 버튼) → 썸네일에서 페이지 선택 → 삭제 / 잘라내기 / 복사 / 선택 페이지 내보내기(추출),
             끌어서 순서 바꾸기, "파일 추가"로 다른 PDF나 이미지(JPG/PNG)를 페이지로 합치기. 바꾼 뒤 Ctrl+S 로 저장.

■ 도구 메뉴
  페이지 회전 저장      현재/전체/범위 페이지를 90°·180° 돌려 파일에 저장 (주석·책갈피 유지)
  서명·주석 박아 넣기   문서에 이미 들어 있는 서명·그림(도장)을 쪽 내용으로 옮겨 저장. 손으로 그린 것까지, 또는
                        형광펜·밑줄·도형·글상자까지 고를 수 있음 (메모 쪽지·링크·양식 칸은 언제나 그대로)
                        박아 넣은 것은 다시 고칠 수 없습니다(저장 전의 파일을 백업하지 못하면 저장하지 않습니다).
                        다음은 박지 않고 그대로 두며 몇 개인지 알려 줍니다: 모양 정보가 없는 주석(한글 글상자 등), 댓글이 달린 주석,
                        남는 주석·양식 칸 위에 겹쳐 있는 것, 투명 그룹 같은 특수한 표시 방식, 전자서명이 들어 있는 문서의 주석.
                        ※ 주석처럼 집어 가는 것을 막을 뿐입니다. 화면 캡처나 전문 편집 프로그램으로 그림을 따내는 것은 막지 못하고,
                          이미 주석으로 저장돼 있던 것을 박은 경우 파일 안의 이전 저장분에는 그 주석이 남아 있습니다.
  용량 줄이기           Ghostscript(PDF24 포함)로 다시 써서 작게. 전자책용 150 dpi 권장. 기본은 "_압축.pdf" 새 파일
                        ※ 이 과정에서 형광펜·메모 등 주석은 사라집니다. 주석이 있는 문서는 원본을 보관하세요.
  잠금(암호) 해제       여는 암호를 알거나, 인쇄·복사만 막힌 문서면 암호 없이 "_잠금해제.pdf"로 풀어 저장 (주석은 빠질 수 있음)
  문서 안의 이미지 추출 문서에 들어 있는 그림을 PNG로 "<이름>_추출이미지" 폴더에 저장
  PDF → 이미지          페이지를 PNG/JPG(100~300 dpi)로 "<이름>_페이지이미지" 폴더에 저장
  PDF → 텍스트          글자만 뽑아 .txt로 저장 (표·2단 배치는 흐트러질 수 있음)
  PDF → Word            Microsoft Word가 변환 (Word의 PDF 열기 기능; 서식은 Word가 재구성)
  그림 → PDF            그림 파일(JPG, PNG, BMP, GIF, TIFF, WebP, HEIC)을 골라 PDF로. 여러 장이면 PDF 하나로 합치거나 그림마다 하나씩.
                        쪽 크기는 "그림 크기 그대로"(여백 없이 그림만) 또는 "A4 용지에 맞춤"(가로·세로 자동).
                        JPG는 다시 압축하지 않고 그대로 넣어 화질·용량이 원본과 같고, 사진의 회전 정보도 반영합니다.
                        PNG 등은 무손실, 투명한 부분은 흰 바탕, 여러 쪽 TIFF는 쪽마다 한 장. 쪽 순서는 만든 뒤 썸네일에서 바꿉니다.
                        촬영 정보(위치·기기 등)는 PDF에 넣지 않고, 색 프로파일(Display P3·Adobe RGB 등)은 그대로 옮깁니다.
                        그림 파일을 창에 끌어다 놓아도 같은 창이 뜹니다. (WebP·HEIC는 Windows에 해당 코덱이 있어야 함)
  오피스·한글 문서 → PDF  Word/Excel/PowerPoint/한글(hwp, hwpx) 파일을 같은 폴더에 .pdf로 만들고 탭으로 엶
                        (해당 프로그램이 설치되어 있어야 하며, 변환 중에는 창 없이 잠시 그 프로그램이 돕니다)
  ※ 용량 줄이기·잠금 해제는 Ghostscript가 있어야 합니다: PDF24 Creator에 들어 있는 것, 또는 따로 설치한 Ghostscript
    (C:\Program Files\gs)를 자동으로 찾습니다. 둘 다 없으면 이 두 기능만 쓸 수 없습니다.

■ 그림 파일 우클릭 메뉴 (등록.ps1 을 실행하면 생김)
  탐색기에서 그림 파일을 고르고 우클릭:
    PDF로 변환          그림마다 PDF 하나. 그림 옆에 같은 이름으로 만들고, 한 개만 바꿨으면 뷰어로 엽니다.
    PDF 하나로 합치기   고른 그림 전부를 파일 이름 순서로 PDF 하나에. "<첫 그림> 외 N장.pdf" 로 만들고 뷰어로 엽니다.
  이미 같은 이름의 PDF가 있으면 덮어쓰지 않고 "이름 (2).pdf" 로 만듭니다. 쪽 크기는 도구 메뉴의 "그림 → PDF"에서 마지막으로 고른 것을 따릅니다.
  Windows 11에서는 우클릭 메뉴의 "추가 옵션 표시" 안에 있습니다 (Shift 를 누른 채 우클릭하면 바로 나옵니다).
  읽을 수 없는 그림(손상, 코덱 없음)은 빼고 만들며 어떤 파일이 빠졌는지 알려 줍니다.
  명령줄: PdfViewer.exe --img2pdf-out 결과.pdf [--a4 | --image-size] 그림1 그림2 ...   (창 없이, 준 순서대로; 종료 코드 0 = 성공)

■ 안 되는 것
  본문 글자 자체를 고치는 편집 (Acrobat Pro 영역), PDF → 엑셀/파워포인트, OCR

■ 기본 PDF 앱으로 쓰기
  PDF 파일 우클릭 > 연결 프로그램 > 다른 앱 선택 > "PDF 뷰어" > 항상
  (또는 설정 > 앱 > 기본 앱 > PDF 뷰어 > .pdf)

■ 단축키
  Ctrl+O 열기 | Ctrl+S 저장 | Ctrl+Shift+S 다른 이름으로 저장 | Ctrl+P 인쇄 | Ctrl+F 찾기
  Ctrl+W 탭 닫기 | Ctrl+Tab / Ctrl+Shift+Tab 탭 이동 | 탭 가운데 버튼 클릭 = 닫기
  Ctrl++ / Ctrl+- 확대/축소 | R 회전(보기만, 저장은 도구 메뉴) | H 손 도구 / S 선택 도구

■ 저장과 백업
  Ctrl+S는 원본 파일을 바로 덮어씁니다. 덮어쓰기 직전의 원본은 아래 폴더에 자동 복사됩니다(최근 40개, 1GB까지).
    %LOCALAPPDATA%\PDF뷰어\backup
  저장 안 한 변경이 있으면 탭 이름 앞에 점, 창 제목 앞에 * 가 붙고, 닫을 때 저장 여부를 묻습니다.
  "선택 페이지 내보내기"와 도구 메뉴의 변환은 원본을 건드리지 않고 새 파일로 저장합니다(용량 줄이기의 덮어쓰기 선택 제외).

■ 폴더 구성
  PdfViewer.exe                 프로그램 본체 (탐색기 우클릭 변환도 이 파일이 --img2pdf 로 불려서 함)
  inject.js                     뷰어와 프로그램을 잇는 스크립트 (툴바 색, 저장 가로채기, 도구 명령)
  start\                        시작 화면 (start.html, logo.png)
  pdfjs\                        PDF.js (Mozilla, Apache-2.0). build\pdf.mjs·pdf.worker.mjs 에 회전 저장·박아 넣기 패치(PDFVIEWER-PATCH)가 들어 있음
  Microsoft.Web.WebView2.*.dll  WebView2 SDK 1.0.4191.47 (Microsoft)
  src\                          소스와 빌드 스크립트 (src\build.ps1 로 다시 빌드, src\patch_pdfjs.py 는 pdf.js 교체 시 패치용)
                                Program.cs 본체 · ImagePdf.cs 그림→PDF · ShellConvert.cs 우클릭·명령줄 변환
  등록.ps1 / 등록해제.ps1       파일 연결·그림 우클릭 메뉴·바로가기 등록 / 해제
  문제가 생기면 %LOCALAPPDATA%\PDF뷰어\log.txt 를 확인. 최근 문서 목록은 같은 폴더의 recent.txt

■ 자체 시험 (고친 뒤 확인용)
  PdfViewer.exe --selftest <결과폴더> <시험용PDF1> [시험용PDF2]
  화면 모서리에 3픽셀만 걸치는 창으로 열기→형광펜→저장→재열기, 두 번째 파일은 새 인스턴스를 거쳐 탭으로, 시작 화면 캡처,
  이어서 회전·압축·잠금 해제·텍스트·이미지·Word 변환, 대화상자·메뉴의 모습(dlg_*.png, menu_*.png), 서명·주석 박아 넣기(자동 저장, 도구, 회전과 함께,
  저장된 서명을 옮긴 경우, 댓글, 겹침, 쪽을 지운 저장, 합친 문서의 저장, 저장 실패, 서명 도구로 실제 서명 만들기), 그림 → PDF(여러 형식의 시험 그림을
  만들어 변환하고 뷰어로 쪽 크기·색을 확인, 우클릭 경로처럼 여러 번 띄워 합쳐지는지)를 돌리고 결과폴더\log.txt 에 기록 (종료 코드 0 = 성공).
  시험용 PDF는 매번 새 복사본을 쓰세요(형광펜과 회전이 저장되어, 같은 파일로 두 번 돌리면 회전 항목이 실패로 나옵니다).
  결과폴더\extra-images 에 그림들을 넣어 두면 그것도 PDF 하나로 만들고 뷰어가 그린 쪽을 extra-pages 에 PNG로 내보냅니다(비교용).
  결과폴더\extra-flatten 에 주석이 든 PDF들을 넣어 두면 하나씩 열어 주석을 전부 박아 넣습니다(그 파일 자체를 고칩니다).
  자체 시험은 결과폴더\data 를 데이터 폴더로 씁니다. 사용자의 설정·최근 문서·백업·브라우저 저장소(저장해 둔 서명 등)는 건드리지 않습니다.

■ 제거
  등록해제.ps1 을 실행한 뒤 이 폴더를 지우면 됩니다. (%LOCALAPPDATA%\PDF뷰어 는 설정·백업 폴더)
